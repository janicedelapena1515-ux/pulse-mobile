## GitHub Releases
- **[Open Releases Page](https://github.com/janicedelapena1515-ux/pulse-mobile/releases)**
- **[Direct APK Download (pulse-mobile-debug.apk)](https://github.com/janicedelapena1515-ux/pulse-mobile/releases/latest/download/pulse-mobile-debug.apk)**

*Note: After pushing `.github/workflows/release-apk.yml`, GitHub Actions takes ~2–4 minutes to compile the Android APK and publish **Pulse Mobile (Latest APK)** under Releases.*

## Installing on Android
1. Download `pulse-mobile-debug.apk` to your Android 7.0+ (API 24+) device.
2. Tap the `.apk` file and allow installation from your browser or file manager if prompted.
