# Download Pulse Mobile APK

## Option 1: GitHub Releases
> **[Go to Repository Releases](../../releases)**  
> **[Latest Release APK Download](../../releases/latest/download/pulse-mobile-debug.apk)**

*Note: These links work once at least one release has been published in this repository's **Releases** section (either automatically by the **Build & Release APK** workflow in **Actions**, or manually via **Releases → Create a new release**).*

## Option 2: Direct Download from AI Studio
1. Open the **Settings / Export** menu in Google AI Studio.
2. Select **Generate APK** to build and download the `.apk` directly.

## Installing on Android
1. Download `pulse-mobile-debug.apk` (or `app-debug.apk`) to your Android 8.0+ device.
2. Open the downloaded file and allow installation from your browser/file manager if prompted.
